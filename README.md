# Merging

Este repositorio contiene la implementación del algoritmo Merge Sort mediante la técnica "Divide and conquer" y sus respectivas pruebas unitarias.

## Instrucciones de Instalación

Para descargar y explorar este proyecto en tu computadora local, ejecuta el siguiente comando en la terminal:

```bash
git clone <URL_DEL_REPOSITORIO>
cd <NOMBRE_DEL_REPOSITORIO>

Verificación de Pruebas Unitarias (Unit Testing)


Este proyecto utiliza pytest para garantizar el correcto funcionamiento del algoritmo de ordenamiento y su lógica de merge


Para ejecutar las pruebas y verificar que todos los casos pasan correctamente, utiliza los siguientes comandos:


#1. Instalar la dependencia de pruebas (si no la tiene)
pip install pytest

#2. Ejecutar el script de pruebas unitarias
pytest Unit_tes_merge_sort.py
